# Three-minute demonstration script

Keep the demo near three minutes by using the time cues and showing the named files while speaking. Use headphones for the generated speech.

| Time | Show | Narration |
|---|---|---|
| 0:00-0:25 | `outputs/` and the selected MP3 | “This activity follows one sample of speech that contains repetitions, blocks, or other disruptions in fluency. The purpose is to study an end-to-end speech pipeline, not to diagnose a speaker. The source recording is about 140 seconds long. I first inspect its waveform and convert it to features that speech-recognition models can process.” |
| 0:25-0:55 | `outputs/waveform.png` and `outputs/log_mel_spectrogram.png` | “The waveform shows amplitude over time. It helps us see pauses and changes in energy, though it cannot identify a stutter by itself. The log-Mel spectrogram maps short-time frequency energy to a perceptually spaced Mel scale. These two visualizations describe the same recording in complementary ways.” |
| 0:55-1:25 | `report/asr_architecture.svg` | “I compare two recognizers. Wav2Vec2 encodes waveform samples and predicts character scores over time. Whisper encodes log-Mel audio features and generates text tokens autoregressively. They are separate model paths; Whisper does not use CTC. The diagram also shows the common text evaluation and text-to-speech output.” |
| 1:25-1:55 | Run `ctc_demo.py` | “CTC means Connectionist Temporal Classification. It lets an acoustic model emit a token at each frame without requiring exact frame-to-letter alignment. The decoder first merges adjacent repeats, then removes blank tokens. Order matters: an intervening blank allows two identical letters to remain two letters. This is why CTC can turn a longer frame sequence into a shorter transcript.” |
| 1:55-2:25 | `outputs/wer_results.csv` and `wer.py` | “I calculate word error rate as substitutions plus deletions plus insertions divided by the number of words in the reference. The current comparison is provisional: the project does not yet contain an independently checked human transcript. The metrics are useful for demonstrating the calculation, but they should not be presented as final model accuracy until the reference is verified against the recording.” |
| 2:25-2:50 | Show `tts.ps1` after successfully generating the WAV | “For the return path, I pass the current Whisper transcript to Windows speech synthesis. The output is a new synthetic performance and does not preserve the original stuttering behavior.” |
| 2:50-3:00 | Summarize | “The project now includes audio features, two ASR outputs, a CTC demonstration, comparative WER, synthesized speech, a notebook, and this report. The key next step for reliable accuracy results is validating the reference transcript.” |

**Before presenting:** run `main.py`, `asr.py`, `whisper_asr.py`, `wer.py`, and `tts.ps1` in that order. Confirm the WAV plays. Replace the provisional reference transcript with a human-verified transcript before quoting WER as an accuracy result.
